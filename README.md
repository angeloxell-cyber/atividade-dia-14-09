# Projeto Monochampion LoL


## Objetivo

Apresentar de forma organizada as vantagens, limitações e métodos de treino de um jogador que escolhe se especializar em um único campeão.

## Estrutura do projeto

- `html/` — 12 páginas HTML com menu de navegação em todas elas.
- `img/` — imagens locais usadas com `figure` e `figcaption`.
- `audio/` — arquivo de áudio local.
- `video/` — arquivo de vídeo local.

## Páginas

1. index.html — página inicial
2. monochampion.html — definição
3. vantagens.html — benefícios
4. desvantagens.html — limitações
5. escolha.html — escolha do campeão
6. treino.html — plano de treino
7. matchups.html — estudo de confrontos
8. rotina.html — rotina de ranked
9. ranking.html — acompanhamento de evolução
10. midia.html — áudio, vídeo e figura
11. faq.html — perguntas frequentes
12. formulario.html — formulário avançado

## Recursos HTML utilizados

Tags semânticas: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`.

Multimídia: `audio`, `video`, `figure`, `figcaption`.

Formulários: `date`, `file`, `color`, `range`, `required`, `placeholder`, `datalist`, além de `fieldset`, `legend`, `radio`, `checkbox` e `textarea`.

Elementos interativos: `details` e `summary`.

Marcação de texto: `abbr`, `mark`, `blockquote`, `cite`, `del`, `ins`, `progress` e `meter`.

## Como executar

Abra a pasta do projeto no VS Code e depois abra `html/index.html` no navegador. Também é possível clicar duas vezes no arquivo `index.html`.

## Expansão avançada
O projeto agora inclui páginas exclusivas para Zed, Irelia e Rengar, além de páginas sobre limites do campeão e macro jogo. As páginas abordam combos, power spikes, queda de poder, builds situacionais, split push e tomada de decisão.


## Novas páginas
- `obrigado.html` — confirmação exibida após o envio do formulário, com agradecimento e próximos passos.
- `desafio7dias.html` — desafio de sete dias para transformar o perfil monochampion em um plano de treino.
